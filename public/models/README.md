# Heart models (drop-in)

Put your anatomical heart file here:

```
heart-animated-realistic.glb
```

No Unity required. Download a GLB from Sketchfab / similar, copy it into this
folder, restart the dev server. V3 auto-detects the file
(`HEART_GLB_MODE = 'auto'`).

See `docs/heart-asset-integration.md` for pose tweaks and licence notes.
